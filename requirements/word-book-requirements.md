로컬에서 나 혼자 쓰는, 단어를 입력하고 외운 것을 체크해 학습 상태를 관리하는 간단한 웹 앱.

[핵심 기능]
- 단어 추가: 단어 + 뜻(정의)을 입력해 목록에 추가
- 단어 목록 보기
- 단어 수정 / 삭제
- 외움 체크: 항목별 외움/안외움 상태 토글
- 로컬 영구 저장: 껐다 켜도 데이터 유지 (같은 브라우저/PC)

[제외]
- 상태 필터(전체/외운 것/안 외운 것), 진행률 표시(개수·%), 단어 검색
- 단어 정렬(가나다순/최근순), 백업 내보내기/가져오기
- 로그인/계정/멀티유저, 서버·클라우드 동기화
- 알림/리마인더, 간격반복(SRS) 학습 알고리즘
- 모바일 네이티브 앱, 다국어 UI(i18n)

[기술 결정]
- 프론트엔드: React SPA
- 데이터 저장: SQLite — 런타임 내장 드라이버 사용(`node:sqlite` 또는 `bun:sqlite`, 네이티브 컴파일 불필요)
- 백엔드: Node.js + Express
- 대상 브라우저: 최신 크롬 / 엣지 / 사파리

[전제/제약]
- 로컬 환경에서 빌드·실행·테스트까지 완료 — 실배포·클라우드·CI 인프라는 범위 밖
- 사용자: 본인 1명 (로컬, 단일 사용자)
- 규제/컴플라이언스 해당 없음
- 데이터 모델: 각 항목 = { 단어, 뜻, 외움상태 }
- 산출물 구조: 단일 백엔드 + 단일 프론트 = 유닛 2개
